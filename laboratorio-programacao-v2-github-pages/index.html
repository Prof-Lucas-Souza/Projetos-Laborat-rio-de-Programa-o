Robótica e visão computacional

OBR

O projeto Robô Resgate com Visão Computacional utiliza inteligência artificial e robótica para desenvolver um robô autônomo capaz de identificar elementos do ambiente e auxiliar na simulação de operações de busca e resgate, seguindo os desafios da Olimpíada Brasileira de Robótica (OBR). O sistema integra uma câmera, processamento computacional e algoritmos de visão computacional para interpretar informações visuais e auxiliar na tomada de decisões durante o percurso.

Sobre o laboratório

Aprender fazendo. Criar para transformar.

O Laboratório de Programação é um espaço de experimentação e desenvolvimento de projetos, onde estudantes aplicam conhecimentos de tecnologia para investigar problemas e criar soluções.

Os projetos apresentados abrangem educação inclusiva, robótica, sustentabilidade, ciência e experiências digitais.
